# Сайт-визитка Лены Балтиной (черновик)

Одностраничный сайт стилиста: онлайн-шопинг, капсула и лукбук за 1–2 часа, запись в Telegram `@antikukla`.

## Стек

- **Astro 7 + React 19 + TypeScript.** Страница собирается в готовый HTML, поэтому поисковики и ИИ-ассистенты видят весь текст. React подключается только на двух интерактивных участках («острова»): мобильное меню и блок вопросов.
- **Стили:** глобальные токены в `src/styles/global.css`. Стили компонентов изолированы: scoped-стили в `.astro` и CSS-модули в React (`*.module.css`). Tailwind не используется: для одной страницы это лишняя зависимость, а палитру удобнее менять в переменных.
- **Шрифты локально:** Cormorant Garamond (заголовки) и Manrope (текст), подключены через `@fontsource`.
- **Иллюстрации:** вещи нарисованы в SVG (`src/components/Garment.astro`), внешних картинок нет.

## Команды

Нужен Node.js 22.12 или новее.

```bash
npm install         # установить зависимости
npm run dev         # локальный сервер с автообновлением: http://localhost:4321
npm run build       # проверка типов + сборка в dist/
npm run preview     # посмотреть собранную версию из dist/
```

## Где что менять

| Что | Где |
| --- | --- |
| Все тексты, ссылки, вопросы-ответы | `src/content/site.ts` |
| Цвета, шрифты, отступы | `src/styles/global.css` (блок «Токены») |
| Порядок секций | `src/pages/index.astro` |
| SEO: title, description, Open Graph, schema.org | `src/layouts/Base.astro`, тексты — в `site.ts` (`seo`) |
| Картинка для соцсетей | `public/og.png` (1200×630) |

Неразрывные пробелы (перед «—», после «в», «и», «с» и т. п.) расставляются автоматически: `src/lib/typo.ts`.

### Как заменить заглушки

- **Фото Лены.** Положить файл в `src/assets/lena.jpg`. В `src/components/About.astro` добавить `import lena from '../assets/lena.jpg';` и передать в `<Portrait src={lena} ... />`. Astro сам сделает AVIF/WebP нужных размеров с ленивой загрузкой.
- **Капсулы.** Сейчас в `src/components/Examples.astro` нарисованные доски. Их можно заменить на реальные коллажи тем же способом через `Picture` из `astro:assets` (с согласия клиенток).
- **Отзывы.** В `src/content/site.ts` (`reviews`) и `src/components/Reviews.astro`. Публикуем только с согласия автора.

## Переменные окружения

Скопировать `.env.example` в `.env` или задать в панели хостинга.

| Переменная | Значение |
| --- | --- |
| `SITE_URL` | Полный адрес сайта, например `https://example.ru`. Нужен для canonical, Open Graph и sitemap. |
| `PUBLIC_DRAFT` | `true` (по умолчанию): плашка «Черновик», `noindex` и запрет индексации в `robots.txt`. `false` ставить только после согласования. |

Секретов (токенов, ключей) в проекте нет: формы нет, заявки идут в Telegram напрямую.

## Публикация

Сборка: `SITE_URL=https://ваш-домен npm run build`. Результат — папка `dist/`, это обычные статические файлы.

### Вариант А. Beget или другой хостинг в РФ (рекомендуется для аудитории в России)

С середины 2025 года российские провайдеры замедляют трафик к Cloudflare, поэтому сайт на `*.pages.dev` у части посетителей может грузиться медленно или не открываться.

1. Создать сайт в панели Beget и привязать к нему домен или поддомен.
2. Загрузить **содержимое** `dist/` в `public_html` этого сайта (файловый менеджер, FTP или `rsync` по SSH).
3. Файл `_headers` на Beget не действует (это настройка Cloudflare). Его можно не загружать.

### Вариант Б. Cloudflare Pages

1. `npx wrangler login`
2. `npx wrangler pages deploy dist` — при первом запуске создаст проект и выдаст адрес `*.pages.dev`.
3. Версия Node задана в `.nvmrc`. Кэш для `/_astro/*` и заголовки безопасности — в `public/_headers`.

Важно: проект, созданный через прямую загрузку (Direct Upload), потом нельзя переключить на автосборку из Git.
